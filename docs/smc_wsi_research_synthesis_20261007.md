# 심장이식 병리 이미지 연구: 현재 결과와 앞으로의 방향

기준일: 2026-10-07. 지금까지의 주요 실험과 다음 연구 방향을 정리한 문서다.
세부 실험 조건과 검증 기록은 마지막의 연구노트에서 확인할 수 있다.

## 1. 무엇을 연구하고 있나?

심장이식 후 채취한 조직의 디지털 병리 이미지(WSI)를 이용해 **중등도 이상 급성
세포성 거부반응(ACR 2R/3R)**을 구분하는 것이 현재 주된 목표다.
이 문서에서 ‘양성’은 이 기준에 해당하는 검사, ‘음성’은 기준에 못 미치는 검사다.

한 번의 생검에는 여러 장의 슬라이드와 여러 종류의 염색이 있을 수 있다.
이를 한 검사 건으로 묶어 판정한다. H&E는 기본 조직 염색,
IHC는 특정 물질을 확인하는 면역조직화학 염색이다.

**가장 큰 제약은 양성 환자가 적다는 점이다.** 같은 양성 이미지를 더 자주 보여주거나
판정 기준을 바꾸는 시도를 했지만, 여러 번의 실험에서 꾸준히 성능을 높이는 방법은
아직 찾지 못했다.

## 2. 현재 데이터는 어느 정도인가?

| 구분 | 현재 수 |
|---|---:|
| 환자 | 133명 |
| 검사 | 575건 |
| 슬라이드 | 1,262장 |
| 양성 검사 | 14건, 전체의 약 2.4% |
| 양성 환자 | 11명 |

한 환자가 여러 번 검사받았으므로 검사 575건이 서로 독립적인 환자 575명을 뜻하지는 않는다.
학습을 여러 번 반복해도 새로운 환자가 늘어나는 것은 아니다.

원래 양성은 17건이었으나, **염색 종류 확인이 보류된 슬라이드를 제외하면서 3건이 빠졌다.**
해당 검사는 S1617719, S1742935, S1919367이다. 이미 ACR 양성으로 분류된
검사이며, 다시 확인할 것은 거부반응 등급이 아니라 염색 종류다.

추가 이미지를 확보하기는 어렵다. 다른 자료는 병리 ID 연결이 불확실해 정확한
정답을 붙이기 어렵다. 현재로서는 이를 양성 학습 자료로 바로 추가할 수 없다.

## 3. 지금까지 무엇을 확인했나?

실험은 무작위 설정을 바꿔 5번씩 반복했다. **각 반복의 평균 성능**과
**5개 예측 점수를 합친 성능**은 구분해서 읽어야 한다.

| 시도 | 확인한 결과 | 현재 판단 |
|---|---|---|
| 어떤 염색이 있는지 알려주는 정보 사용 여부 | 모델 구조를 같게 두고 비교했을 때, 반복 평균과 예측을 합친 결과에서 유리한 쪽이 달랐다 | 염색 유무 정보를 빼는 편이 낫다고 결론내리기 어렵다 |
| 슬라이드에서 학습할 작은 이미지 영역을 2,048개에서 4,096개로 늘리기 | 예측을 합친 성능은 높아졌지만, 개별 반복 5개 중 4개에서는 양성 순위 성능이 낮아졌다 | 영역 수 증가가 안정적인 개선책이라는 근거는 부족하다 |
| 양성을 더 많이 찾도록 판정 기준 낮추기 | 평균적으로 검출 양성은 5.6→8.4건, 잘못 양성으로 부른 음성은 26.2→63.6건으로 늘었다 | 더 찾는 만큼 오판도 늘었다. 기본 판정 방식으로 바로 채택하기 어렵다 |
| 양성 검사를 더 자주 뽑아서 학습하기 | 기본 판정 기준에서 양성은 더 찾았다. 다만 양성을 상위에 배치하는 성능은 원래 비율대로 학습한 쪽이 5번 중 4번 더 높았다 | 양성을 반복해서 보여주는 방법이 항상 우월하지는 않았다 |
| 양성을 틀렸을 때 더 큰 벌점을 주기 | 이번 조건에서는 개선되지 않았다 | 추가 실험의 우선순위는 낮다 |

검출 건수의 소수점은 반복 실험의 평균이다. 서로 다른 행은 학습·평가 절차도
다르므로 수치만으로 전체 순위를 매기지는 않는다.

핵심은 **양성을 더 자주 보여주는 것과 새로운 양성 환자를 확보하는 것은 다르다**는 점이다.
반복 노출은 늘었지만 환자 다양성은 그대로였다. 그렇다고 반복 노출이 성능 저하의
원인이었다고 입증한 것은 아니다.

## 4. 성능 지표는 어떻게 읽으면 되나?

| 알고 싶은 것 | 볼 지표 | 쉬운 해석 |
|---|---|---|
| 실제 양성을 높은 순위에 올리는가? | AP, AUROC | 점수가 높은 검사부터 봤을 때 양성이 얼마나 잘 모이는지 평가한다. 양성이 적어 AP를 주 지표로 본다 |
| 실제 양성을 얼마나 찾는가? | 민감도, 검출 양성 수(TP) | 양성 14건 중 몇 건을 찾았는가 |
| 양성이라고 부른 검사 중 얼마나 맞는가? | 정밀도, 위양성 수(FP) | 양성 판정의 신뢰도와 잘못 부른 건수 |
| 검출과 오판을 함께 보면 어떤가? | F1, F2, MCC | F1은 정밀도와 민감도를 함께 보고, F2는 민감도에 더 무게를 둔다. MCC는 양성·음성의 정답과 오답을 모두 반영한다 |
| 예측 점수를 실제 확률로 읽을 수 있는가? | 확률 보정 평가, Brier 점수 | 예측한 20%가 실제 발생 비율 20%와 맞는지는 별도 확인이 필요하다 |

한 지표가 높다고 다른 질문까지 해결된 것은 아니다. 특히 F2가 높아졌다는 것만으로
임상적으로 더 유용해졌다고 볼 수는 없다.

초기 실험은 평가에 사용한 자료로 학습 중 어느 모델을 고를지도 결정했다.
후속 실험은 **모델을 고르는 자료와 최종 평가 자료를 분리**했다.
따라서 초기의 높은 성능을 후속 결과와 그대로 비교하면 안 된다.
학습 자료의 양과 방식도 달라졌으므로 성능 차이 전체를 평가 방식 탓으로 돌릴 수도 없다.

현재 불확실성 분석도 이미 학습한 모델을 고정한 상태의 결과다.
새 환자에서 다시 학습했을 때 얼마나 달라질지까지 모두 검증한 것은 아니다.

## 5. 관련 문헌은 무엇을 설명해주나?

추가 문헌 7편은 아래 해석을 뒷받침한다. 다만 주로 일반적인 예측 방법 연구이며,
우리 심장이식 이미지에서 같은 원인이 작동했다는 증거는 아니다.
검토 범위는 각 논문의 요약 등 지정한 페이지다.

| 연결되는 내용 | 문헌에서 얻은 근거 |
|---|---|
| 양성·음성 비율을 인위적으로 맞추는 방법 | 항상 성능을 높이지는 않으며, 예측 확률을 왜곡할 수도 있다. [van den Goorbergh, 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9382395/), [Carriero, 2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC11771573/) |
| F1 외 지표와 판정 기준 | F1만으로 평가하기는 부족하고, 최적 판정 기준도 점수의 성질에 따라 달라진다. [Chicco, 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC6941312/), [Lipton, 2014](https://arxiv.org/abs/1402.1892) |
| 적은 자료에서의 평가 | 모델을 고르는 데 쓴 자료로 성능까지 평가하면 낙관적인 결과가 나올 수 있다. 반복 실험의 편차만으로 전체 불확실성을 설명하기도 어렵다. [Cawley, 2010](https://www.jmlr.org/papers/v11/cawley10a.html), [Varoquaux, 2018](https://pubmed.ncbi.nlm.nih.gov/28655633/) |
| 표본 수의 적절성 | 검사 수뿐 아니라 환자 수, 양성 수, 모델 복잡도를 함께 봐야 한다. [Riley, 2020](https://www.bmj.com/content/368/bmj.m441) |

문헌 요약과 출처는 [문헌 저장소](../reference/README.md)에 정리돼 있다.

## 6. 먼저 정리할 것

1. **반복해서 놓친 양성 사례를 살펴본다.** 불균형 처리 실험의 모든 방식·반복에서
   기본 판정 기준으로 놓친 7건, 5명의 이미지와 기록을 대조한다. 조직량, 이미지 품질,
   염색, 자료 수집 경로를 확인하되 모델이 틀렸다는 이유로 정답을 바꾸거나 제외하지 않는다.
2. **보류된 양성 3건의 염색 종류를 확인한다.** 다시 포함할 수 있다면 별도 데이터
   버전으로 비교한다. 기존 결과는 보존한다.
3. **어떤 검사에서 염색 비교가 가능한지 센다.** H&E만 있는 검사, H&E와 IHC가 함께
   있는 검사별로 전체 수와 양성 환자 수를 정리한다.

이 세 가지를 먼저 확인하면 다음 실험이 실제로 가능한지, 양성이 얼마나 더
줄어드는지 판단할 수 있다.

## 7. 앞으로 어느 방향으로 연구할 것인가?

### 추천하는 중심 질문

> **양성 환자가 적은 상황에서, 여러 염색의 이미지를 함께 보면 H&E만 볼 때보다
> 거부반응을 더 잘 구분할 수 있는가? 그 차이가 ‘어떤 염색을 했는지’라는 정보만으로도 설명되는가?**

지금까지 쌓은 염색 분류, 검사별 이미지 묶음, 불균형 대조를 이 질문으로 연결할 수 있다.
최고 성능 하나보다 **추가 염색이 언제 도움이 되는지**를 밝히는 방향이다.
아래는 아직 실행하지 않은 제안이다.

### 다음 실험의 우선순위

| 순서 | 비교할 내용 | 이 비교가 필요한 이유 |
|---|---|---|
| 1. 단순한 모델과 비교 | 이미지 특징(모양을 수치로 요약한 정보)을 평균 내고 단순한 분류기로 판정한 결과와 기존 모델 비교 | 지금 모델의 복잡도가 실제 이득을 주는지 확인한다 |
| 2. 이미지 없이 비교 | 염색 종류·슬라이드 수·자료 수집 경로만 사용하는 모델과 이미지 모델 비교 | 조직 모양 외의 정보만으로도 예측되는 부분이 있는지 확인한다 |
| 3. 추가 염색의 효과 비교 | 같은 검사에서 H&E만 사용하는 경우와 IHC 등 추가 염색까지 사용하는 경우 비교 | 비교 대상이 달라서 생기는 차이를 줄이고 추가 정보의 가치를 확인한다 |

비교할 때는 같은 환자들이 같은 학습·평가 집단에 들어가도록 맞춘다.
최종 평가 자료로 모델이나 판정 기준을 고르지 않는다. 양성 환자가 너무 줄어드는
비교는 규모를 먼저 확인하고 진행 여부를 정한다.

결과에 따른 판단은 다음과 같다.

- 단순한 모델도 비슷하다면 더 복잡한 모델로 확장할 필요성은 낮아진다.
- 염색 종류와 수집 경로만으로도 잘 맞힌다면 이미지 모델이 무엇을 이용하는지 더 확인해야 한다.
- 추가 염색이 여러 반복에서 도움이 된다면 그 염색과 사례의 특징을 후속 주제로 삼는다.
- 차이가 불분명하면 현재 표본으로는 구분하지 못했다고 보고한다. 정보가 없다는 결론은 아니다.

여러 염색을 함께 활용하는 방법과 자료 수집 경로의 영향을 다룬 선행 연구도 있다.
우리 데이터에서의 이득은 별도 확인이 필요하다.
([MADELEINE](https://arxiv.org/abs/2408.02859),
[Howard 등](https://www.nature.com/articles/s41467-021-24698-1))

### 추가로 검토할 아이디어

- **의사에게 먼저 보여줄 검사 고르기:** 기존 예측에서 점수가 높은 상위 5%·10%·20%를
  검토하면 양성을 몇 건 찾는지 정리한다. 자동 판정 성능과 다른 활용 가능성이다.
  실제 업무에서 도움이 되는지는 이후 검증이 필요하다.
- **병변이 있는 부분에 집중하기:** 오류 검토에서 작은 병변이 전체 이미지에 묻히는
  문제가 확인되면 검토한다. 모델이 강조한 위치가 실제 병변인지는 의사의 확인이 필요하다.
- **다른 거부반응으로 확장하기:** AMR(항체매개성 거부반응) 등은 정답의 신뢰도와
  양성 환자 수를 먼저 확인한다. ACR과는 별도 결과로 평가한다.

라벨 없는 이미지로 추가 학습하거나 미래 임상 경과를 예측하는 방향은 필요한 자료와
평가 조건이 마련됐을 때 검토한다. 현재는 추가 자료 확보를 전제로 계획하지 않는다.
학습 기간을 늘리는 대조는 기존 논의대로 보류한다.

**가장 가까운 다음 산출물은 ‘오류 사례 정리표’와 ‘염색별 비교 가능 환자 수 표’다.**
이를 바탕으로 첫 비교 실험을 정한다. 현재 결과만으로 임상 적용 성능이나 양성 부족을
해결했다고 주장할 단계는 아니다.
